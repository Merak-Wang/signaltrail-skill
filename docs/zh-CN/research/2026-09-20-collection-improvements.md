## 实现结果

正式报告仍为 32 个来源，每源 15 条摘要。发现层现有 60 个配置：57 个启用、3 个待接通。
新增启用的六个来源扩充地区报道、政策表态和机构记录，不产生新增摘要配额或模型调用。
机构来源、报道范围和出版组分别记录；这些字段不证明材料互相独立，也不核实发言者的主张。

## 实现内容

- `feed_content` 将来源长字段保存为结构块、链接、图片和网站原图注，分别处理 RSS HTML、
  Atom text/html/xhtml、继承语言及嵌套 xml:base。文件名由内容哈希决定，同 URL 更新生成
  新文件，相同内容复用既有文件。列表 description 仍最多 600 字符。
- 只有被选中富化的条目才加载 Feed 记录为部分正文；网页补全失败时保留已有证据及其限制。
  不按 Feed 长度升格 full_text；未选条目保持原候选边界和 not_fetched 状态。
- 每个来源独立推进 Feed 与替代入口发现，已知 Feed 不再等待其他首页发现结束。
  Feed 和 HTML 请求先取得同域许可，再占全局名额，避免同域等待挤满全局网络池。
- 发现阶段先分类 429/403，再处理一般错误。Retry-After 保存到现有登记表，冷却期不再
  请求发现页或切换 HTML 通道。失败后复用的 Feed 缓存在退避期仍标记 stale/partial。
- HTTP 预取与正文抽取共用流式字节上限，截断索引明确为 partial/failed。
  索引和正文图片候选补入 picture/source 与 data-srcset。
- 浏览器回退使用单个持久化 context 内的异步页面池，限制全局和同域页面数，按原顺序输出。
  就绪条件替代通用固定等待，保留站点显式等待。六个内置适配器与同步验证入口共用抽取脚本
  和条目转换函数。

回归测试覆盖长文末尾条件、真实嵌套 XHTML 图片和图注、纯文本与 HTML 区别、编码声明、
缺正文、同 URL 更新、相同内容复用、写作投影边界、发现调度、跨域饥饿、流式截断、429 冷却、
访问失败、浏览器生命周期、就绪等待和来源顺序。最终使用仓库虚拟环境通过完整门禁：**553 项测试**、Ruff、compileall、中文注释检查、
文档检查及 `git diff --check`。

另用真实无头 Edge 访问本地 HTTP 样例，测试了六个内置适配器：通用索引、arXiv、TWZ、
最新年度目录、微博 JSON 和 Seed API。每项均成功返回一个预期条目，通用索引也选中了响应式
大图。浏览器 profile 和公开源实测产物均放在仓库外。

本次没有实现研究证据授权、并行长文写作、专题绑定或当前新闻准入；这些属于方案后续研究工作。
