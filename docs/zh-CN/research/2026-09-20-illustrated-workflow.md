## 设计与实际行为

日报与研究消费各自冻结的输入。`research prepare` 只需要规范索引和显式选定的文章 ID，
不要求最终日报。原始正文块、时间、正文状态与来源被有界复制到既有不可变 narrative 存储。
输入索引的指纹只记录出处，不成为后续可变依赖；日报继续抽取不会让已派发研究失效。
可用 `--discovery MONITOR.json` 选择发现层的显式 ID，保留所选 Feed 正文块，不升级正文状态或改变日报配额。新材料通过 `--previous` 创建新快照；支持文字改变会重新打开受影响的问题。

`research search` 复用项目英文词项、中文二元组，对来源块做 BM25 检索。
`research select` 按未答问题的加权新增覆盖贪心选择，并压低相同原始记录或完全同文的重复。
没有新问题获得候选时停止。这是相关材料建议，不是自动回答或独立佐证。
没有跨语言语义检索；翻译后的问题应附原始语言关键词。

问题账本区分已回答、部分回答、有争议、未建立；更新不会删除未提及的问题。
底稿记录条件、反解释与可观察的检验项；研究分析分配 `RA-` ID，研究证据分配 `RE-` ID。
复用原主张编译、单语脚本和隔离审核。研究推断不能借用原日报的分析 ID，
也不能超出自身分析所引用的前提片段。

写作只读取所需的[中文](../../../templates/research-style-zh.md)或
[英文](../../../templates/research-style-en.md)风格卡。新增可选表格将表头、单元格、
编辑图注全部登记成可审核片段。原创整理表的来源原图注为 null；仍不准入外部纪实图片。
单语图文可使用绑定该脚本的支持性审核；双语仍须双语一致性回执。

`research bind` 核对真实完成日报，登记补充、限定或异议关系，不给旧日报授权新事实。
`research render` 生成独立 HTML 修订，研究放在原三视角和跨视角综合之后。
JSON、Markdown 保存父引用与文字；Markdown 以附录放置研究。
原日报 JSON、Markdown、HTML、连续状态和运行状态均保留。日报完成函数不调用或等待研究；
资源保留与模型派发仍由宿主负责。

## 设计依据

STORM 将写前调查与大纲构造分开，作者也指出来源偏差传递和不恰当关联等问题。
这支持借用问题驱动的准备方法，但不能将更多视角当成正确性的证明。
[Shao 等，NAACL 2024](https://aclanthology.org/2024.naacl-long.347/)。
ALCE 分开评估流畅性、正确性和引用质量，支持分别检查表达与证据。
[Gao 等，EMNLP 2023](https://aclanthology.org/2023.emnlp-main.398/)。
上述是从论文推导的设计选择，不是 SignalTrail 实测收益。

## 可复现组件对照

运行 `python scripts/evaluate_research_workflow.py --output output/research-workflow/benchmark.json`。
固定样本包含四个中文和四个英文问题。相关词特意只出现在已保存正文块中，
两种方法使用相同文章和截止时间。

| 指标 | 观测结果 |
| --- | --- |
| 仅标题词项检索 Top-1 命中 | 0/8 |
| 正文块 BM25 Top-1 命中 | 8/8 |
| 首次冻结八篇文章 | 46.180 毫秒 |
| 热检索 160 次 p50 / p95 | 3.163 / 4.442 毫秒 |
| 本组件实验的网络 / 模型调用 | 0 / 0 |
| 环境 | Windows，Python 3.12.11 |

结果只证明构造样本中正文里存在、标题里缺失的信息能被找到，不能外推为生产质量提升率，
也不是与某个已有完整正文检索器的优劣比较。耗时包含本地文件加载，受文件系统与缓存影响；
尚无真实晨晚报 p50/p95 或 token 节省结论。

行为测试覆盖日报前准备、上游更新时的冻结文字、中文检索、同源重复、问题保留、
证据更正、推断范围、表格审核、单语回执绑定及不可变组合输出。
原日报和讲解测试继续作为回归基线。实际运行文件放在被忽略的 `output/` 或配置数据根，不进 Git。

## 验收边界

中文阅读样稿使用两篇原论文摘要，包含三章、一幅流程示意、一张对照表。
隔离审核核对了修订稿的 27 个可见片段、33 项断言和全部 6 项登记主张。
初审发现三个有实质含义但未登记引用的章节标题，以及一句超出证据范围的资料获取状态断言。
一次作者修订完成修复并增加具体例子，真实接收器返回零阻断发现。
模型编辑分为清晰度 4/5、叙事 4/5、解释 4/5（修订前解释为 3/5），仍保留一项机制讲解建议。
这些评分不是写作盲评，也不是测得的读者理解改善。

1440、820、390 像素的桌面、平板、手机检查中，独立样稿及组合示例均没有整页横向溢出。
独立样稿保留三章、一表、一示意图，外部资源依赖为零。
组合示例保留原三个分析领域，研究位于评估之前。父报告使用仓库 7 月 12 日历史示例，
明确标为测试而非当期日报。两条路径的审核输入完全相同，因此复用同一次真实语义判断，
并分别保存与各自脚本绑定的回执。

命令将研究者声明的问题覆盖与语义正确率、独立佐证数、读者理解和用量分开，未观测项为 null。
模型支持性审核不是读者理解实验。配套阅读样稿采用历史研究文献，不是真实当期新闻日报。
自动定向网络研究、可靠的转载来源判定、宿主计量派发、外部照片准入及连续三期真实验收仍未完成。
实时新闻模式保持阻断。见[技术债](../../exec-plans/tech-debt-tracker.md) TD-038、TD-041
及[运行步骤](../../../references/research-workflow.md)。
