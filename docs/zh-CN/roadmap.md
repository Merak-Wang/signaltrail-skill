## 预期结果

先提供面向有一定背景中英文读者的分章节讲解：发生什么变化、还需要什么背景、机制如何运作、
可以合理推导出什么。在“研判”区域的组合阅读视图里加入讲解，并自然引入既有专业判断及其条件。
子产物不重写已保存的父报告；只读旧报告的程序仍保持兼容。

用户已确认中文说书节奏与英文小说式叙事连贯性，两者均保留专业分析。
基于同一 claim/analysis 底稿分别写作，不要求逐句对译；保存各语言修订，
核对关键事实、时间、归因、因果、情景条件与判断强度。已有单语报告 Schema 不混写两种语言。
“小说式”指结构与表达，不意味着可以编造场景、对话、动机或结局。

每个事实或推断关联已接纳证据或已授权分析依赖。beat 是读者可见的一小组相关主张。
每章回答一个问题，不同机制分章表达。保留完整稿以便修订核验，再单独做口语编辑；
不通过虚构场景、动机、引语、反方或结局制造故事。

独立验证者从全文重新提取主张，包含标题与转场，检查证据、归因、时间、不确定性、矛盾，
并对照必讲事实查遗漏。关键发现未解决时保持 Draft。
版本化 JSON 与 Markdown 保留已接纳语义，HTML 是可重建视图。

本轮还交付有序图文清单和适合手机/桌面的阅读页：时间线、机制图、数字比较、归因观点、
证据缺口与相关授权图片。初版可以原样复用已核文字。新写的卡片标题、短文、图注、图表标签、
替代文字须绑定图文修订并经过语义复核；渲染器不生成或改写语义内容。

下一轮再增加语音、实测字幕和视频。当前只保留稳定 beat/claim/asset 引用，
不预造音频时长，也不提前固定引擎。公开平台发布、平台算法优化与直播不在本轮范围内。

## 边界

```text
已完成报告 + 索引 → 有界证据与编辑意图 → 主张/时间检查
→ 提纲与讲解稿 → 独立核验 → 当前讲解回执
→ 图文/素材草稿 → 语义和视觉复核 → 已接纳图文清单
→ 版本化 Markdown + HTML

下一轮：已接纳图文清单 → 语音 / 实测字幕 / 视频
```

Python 负责 ID、修订、Schema、证据授权、哈希、新鲜度和准入。
模型只写作或评判自己的数据包，作者与验证者上下文隔离；第二次模型调用不等于第二个独立来源。
下游不能写回父报告、索引或连续状态。重新检查发现新事实时，先通过上游采集和报告/索引新修订，
再恢复讲解写作。

每份语义产物具有不可变修订与父级哈希。回执绑定讲解稿、核验、父报告/索引、数据包和策略；
图文回执还绑定清单及其审核。加载器检查递归父级依赖和精确 claim/beat 覆盖，
不能扫描“最新文件”或接受作者自报通过。父级、证据、策略或语义改变需要新决定。
旧回执保留历史；绑定仍有效时复用已完成工作。拒绝尝试与中断状态应可观察。

内容核验、当前准入、投影状态分开保存。已接纳历史修订可能不再适合作为当前新闻，但不能覆盖历史。
讲解或图文失败不撤销有效报告；素材失败有确定性的文字/自制图备用方案。
初版只接纳 completed 报告，partial 报告支持需要单独策略。

素材保留 beat、来源、主体/时间上下文和允许用途。现有安全下载不等于权利回执。
未知权利或无法核实的画面不能进入正式卡片；图表保留单位、时间范围、不确定性与文字替代。

确切 Schema、模块名、beat 大小和渲染 API 随原型确定。下文预算与门槛均是候选，
应在正式验收前冻结，不应当作已经实现的默认值。

## 时间与证据准入

分别保留事件时间及精度、发布时间、来源更新时间、抓取时间/指纹、讲解截止时间/时区、检查时间。
未知保持未知；采集时间不能让旧闻变成新消息。预定事件的未来日期可以合法存在，
但必须表达为计划；来源发布时间在未来属于另一种验证问题。

写作前、发布或延迟渲染前检查关键状态，并检查原发布方的更正/更新链：旧网页未变，
不代表没有另发新 URL。旧草案的 120 分钟软有效期仅作为普通新闻待测上限，
变化快的主张需要更严格检查；以版次窗口边界为硬到期，到达边界即拒绝。
访问失败、必要来源缺失、重要冲突未解决会阻断当前准入，但不撤销父报告。
记录精确检查范围与时间。

新鲜度作用于逐条主张，允许同一 beat 含历史与当前事实。
标题或 beat 标签不能把新鲜度传给无关证据。证据集合变化或相对时间措辞过期需要新的语义决定；
证据变化时须先修订上游报告。定向措辞修复不授权作者自行新增研究。

## 验收

保留 G0—G7 以便对照历史计划：

| 检查 | 要求 |
| --- | --- |
| G0 父级绑定 | 已完成报告及匹配索引，ID 和哈希通过检查 |
| G1 证据与新鲜度 | 主张在所述时间得到支持，更新链已查，不把未知或过期证据作为当前有效 |
| G2 叙事质量 | 解释清晰、分析/异议有据、不确定性明确，理解效果达到版本化门槛 |
| G3 独立核验 | 精确 claim/beat 覆盖、独立提取断言、必讲事实及更正无遗漏、无关键未解决问题 |
| G4 成本与观测 | 阶段用量可归因，partial/unknown 明确，符合记录预算 |
| G5 修订与恢复 | 不覆盖、安全重放、中断明确、并发经过测试 |
| G6 阅读投影 | JSON/Markdown 与 HTML 语义及链接一致，渲染不改写语义 |
| G7 图文准入 | 讲解/图文决定当前有效，文案/视觉主张已核、素材用途明确、有文字替代和备用方案；声音/播放留给 V1 |

总分不能抵消证据、身份、核验或权利失败。真实验收前冻结范围、提示词/模型策略、Token 上限、
时间预算和质量标准。正式整期暂沿用范围候选：6—10 个精选事件、至少 60% 的独立精选事件覆盖、
三个分析视角；以已接纳主张计数，不以装饰性的章节引用计数。单章节样稿不能绕过整期验收。

候选验证集沿用 32 例划分：8 个事实、8 个时间、8 个因果/认知、4 个注入、4 个正确对照。
两次独立运行分别要求关键缺陷全发现、非关键召回至少 90%、正确对照 4/4 通过。
缺陷分母和人工标注要版本化；有限测试全过不代表生产零错误。初始共享修复预算建议一次。
在相同冻结证据上比较单次 prompt 与分阶段流程，记录 Token、用时、遗漏、理解效果和风格。

人工审阅记录实测朗读问题，检查读者能否解释变化、背景、机制、不确定性、观察点。
初始候选为五个理解问题至少准确回答四个，且不混淆核心事实与推断。
先校准评分标准与评阅者再冻结；模型自评分不能替代人工审阅或朗读时长测量。

中英文分别让目标读者检查理解效果。完整双语包必须同时绑定两份语言修订的当前决定及一致性审核，
不能把单语成功宣称为双语整期完成。一种语言待处理时，明确可用范围并保持独立重试。

至少两个宿主连续三期实跑，记录所有父/子修订、用量覆盖、耗时、决定、读者审阅与阅读投影。
一期失败，修复后重新开始连续验收。缺失用量保持未知，不能支持精确节省结论。
实现音视频后另做独立实跑序列。

现有实现缺口继续保留在[技术债追踪](exec-plans/tech-debt-tracker.md)。
