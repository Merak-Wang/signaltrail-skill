# 叙事型研判规范

**权威语言：** 中文（单语运行参考）
**负责人：** 仓库维护者
**状态：** 已验证写作规范
**最后对照代码：** 2026-10-07
**文档目录：** [`docs/README.md`](../docs/README.md)

研判采用两层结构：

- **读者层**：`claim` 是文章标题，`narrative` 是可独立阅读的主文。
- **支撑层**：事实、推理链、历史脉络、辩证分析、立场、反证、情景、假设、影响、行动、观察信号、失效条件和置信度依据组成论证底稿。

支撑层必须完整、可追溯，但不得直接充当正文提纲。先用支撑层完成分析，再重写 `narrative`；发布界面默认突出主文，并把支撑层放入可展开的“论证与证据”。

## 选择一条主线

每篇主文只回答一个中心问题，并围绕一个可证伪判断展开。引用多个事件前，先用一句话说明它们共享的机制。共享日期、领域标签或抽象词不是机制。

以下情况应拆开处理或只选其中一组：

- 事件之间没有共同因果链；
- 一个事件只能充当气氛或类比，不能改变判断；
- 为了覆盖更多新闻而同时讨论战争、技术、市场或国内政治；
- 文章必须在“不确定性”中承认前文拼在一起的事件其实相互独立。

三个视角可以各自引用精选 dossier 的一个连贯子集；三个视角合计满足覆盖要求即可。不得为了让单篇文章显得“全面”而塞入不服务主判断的事件。跨视角综合也不得暗示独立事件存在统一协调。

## 让分析方法体现在论证中

辩证法用来决定怎样组织材料：

- 写清行为体想获得的收益，以及该行动产生的反作用和新增成本；
- 指出主要矛盾、次要矛盾及主次转换的条件，但不要机械使用这些术语；
- 区分推动因素、制约因素、内部条件和外部条件；
- 说明量的积累何时可能跨过阈值，改变局势性质；
- 给出最强反方、替代解释和会推翻判断的新事实。

历史唯物主义用来解释能力和约束：

- 追踪技术、资本、能源、物流、产业能力、国家利益和制度安排；
- 讨论谁控制资源、谁承担成本、谁有修复或替代能力；
- 只引入能解释当前机制的历史，不写与判断无关的背景百科。

正文不要出现“下面进行辩证分析”“主要矛盾是”“历史唯物主义告诉我们”等方法展示。读者应从因果、条件、反作用和证伪边界中感受到方法。

## 主文的推进方式

`narrative` 通常写 4—7 个自然段，不设“事实基础”“历史脉络”“辩证分析”等内部小标题：

1. **开门见山**：用具体场景、变化或反常识判断回答“今天真正变了什么”，避免“本期最重要的变化不是……”等固定套话。
2. **把事情讲明白**：按时间、因果或利益冲突组织关键事实；每个事实都要推动判断。
3. **解释机制**：说明压力怎样在主体、产业、制度或市场之间传导，并自然呈现收益与反作用。
4. **处理反方**：说明最强反证及其如何改变判断，保留有分析价值的具体条件。
5. **落到后续**：给出条件化情景、最值得观察的信号，以及这些信号会怎样改变判断或行动。

可以调整段落顺序，但要让读者始终知道当前段落是在回答“发生了什么”“为什么重要”“哪里可能判断错”还是“接下来观察什么”。建议必须对应前文某个因果节点，不得另起愿望清单。

## 直接表达与局限性

主文直接推进事实、机制、判断和后续观察，避免上一句说明、下一句又用“不代表”“不证明”“并不意味着”等防御性否定。计划、涉嫌、来源声称等事实限定随原句自然交代。确有影响判断的重大隐患、类比关键差异或证据缺口需要解释时，集中写入 `narrative` 最后一个以“局限性：”开头的自然段；英文使用“Limitations:”。该段计入原有 4—7 个自然段，末尾可交代对应观察信号。详细论证继续保存在 `counter_evidence`、`assumptions` 和 `evidence_gaps` 等现有字段；无需新增字段，也不例行添加免责声明。

## 类比与故事

具体故事和历史类比可以降低理解成本，但必须满足：

1. 先说明相似对象；
2. 主动指出关键差异；
3. 只保留真正相同的机制；
4. 再把机制带回当日事实。

没有真实亲历时不得虚构第一人称经历。找不到共同机制时不使用类比。

## 完稿检查

交付前逐项确认：

- 只读 `claim` 和 `narrative`，读者也能复述中心判断、原因、边界和下一步；
- 每个引用事件都对因果链构成实质支持，删除后会明显削弱论证；
- 推断没有伪装成事实，置信度与访问等级一致；
- 最强反方在主文中清晰可见；
- 历史、立场和建议都服务同一主线；
- 支撑字段与主文不矛盾，且能逐项追溯主文中的关键判断；
- 没有虚构故事、宏大空话、同日事件硬拼或字段内容的机械串联。

## 逐项核对证据与修订

对照引用时检查整条主张及其上下文，不只检查引用 ID 是否存在。逐项核对 `claim`、`narrative`、执行摘要、精选事件、跨视角综合和观察信号中的事实断言；确认来源证据支持具体行为体、地点、时间、行动状态和因果关系。引用不支持原句时，删除无依据内容或缩小断言范围；不得只替换引用 ID，却保留原来的无依据说法。结构验证只能确认字段、引用身份和格式约束，不能证明事实准确。

独立评估发现事实问题后，保留已保存报告及其评估，按正常工作流修正并生成新的不可变报告修订，再对新 revision 运行独立评估。不得原地改写旧报告，也不得把旧 revision 的评估当作新 revision 的评分。
